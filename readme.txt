A free, India-first block theme for nonprofits and NGOs.

== Description ==
Nonprofit Seva gives small Indian nonprofits a credible website without an agency budget.

Built-in page patterns:
* Donate page with an 80G tax-benefit note and a UPI/QR-friendly layout
* Transparency page for 80G, 12A, FCRA and CSR-1 certificates, annual reports and audited financials as downloads
* Programs grid, impact stories and impact stats that look complete with no photos
* Volunteer signup with email/WhatsApp fallback actions (no plugin required)
* Trustees section and a registration-numbers footer

Design: clean and light, one accent color changeable via style variations, system fonts for fast loading on budget phones, WCAG AA color contrast.

The theme works fully with no plugins. For online donations it styles the free GiveWP plugin to look native. No bundled plugins, no shortcodes, no custom post types, no forms.

== Installation ==
1. In your WordPress admin, go to Appearance > Themes > Add New > Upload Theme.
2. Choose the theme zip and click Install Now, then Activate.
3. Open the Site Editor or add a page and insert patterns from the "Nonprofit Seva" categories.

== Frequently Asked Questions ==
= Does it need any paid plugin? =
No. Everything in the theme is free and works with zero plugins.

= How do I show my 80G certificate? =
Add the Transparency page pattern, upload your PDFs into the file blocks, and edit the registration list.
